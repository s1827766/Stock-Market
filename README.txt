DAY 4 - RELATIONSHIPS + NORMALIZATION

Run these scripts from the SAME folder as trading.db.
1) create_relational_copy.py rebuilds a clean learning copy with stocks + relational_prices.
2) Read the worked JOIN example in join_practice.py (annotate it on paper first) -- this one is
   given to you, you don't need to write it yourself.
3) Complete the 3 required JOIN challenges on paper first, then write them into join_challenges.py.
4) Use normalization_practice.txt for the paper-first normalization exercise.

IMPORTANT: use relational_prices, not prices, in every JOIN today. prices does not have a
stock_id column -- only relational_prices does.

create_relational_copy.py is intentionally safe to re-run: it rebuilds only the Day 4 learning-copy tables.
